# Inventory
Spreadsheet-style inventory of registered controlled documents (nav label may say **Database**).

## On this page
- Type pills: ALL + parent document types
- Search and **Filter** panel (sub-type, originator, source, received-by, status, revision status, dates, rev no)
- **Export CSV** / export all columns option
- Wide grouped table (masterlist / DRF / DCN / distribution column groups); expand revisions/courses

## Right-click context menu
- **Edit**
- **Register revised**
- **Register recur**
- **Print for distribution**
- **Generate distribution sheet**
- Hide/show column groups

> [!TIP]
> Dashboard Total/Latest chips link here when you have Inventory (Database module) access.
