# Manage Files
Browse DCS files in a Google Drive–style explorer (My Drive).

## On this page
- Search
- View modes: **Tiles / List / Details**
- Folder breadcrumbs; open PDFs in a new tab
- File pagination when needed
- If your account has no office/storage access: restricted message + **Back to Dashboard**

> [!NOTE]
> This screen browses/opens files. Upload and delete are not provided on this page UI.
