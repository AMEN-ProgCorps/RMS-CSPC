# New Document Change Notice (DCN)
Create form CSPC-F-DCC-01 to revise an existing controlled document.

## Before the form
- Find the document to revise: Required. Enter registered document no., current title, and originator, then Find document and pick the match. Only then can you save.

## Fields
- New document title: Title for the revised document.
- Detailed Description of Change:
  - From: Current text or content being changed.
  - To: Replacement text or content.
- Justification of Change: Reason for the change.
- Originator: Originator for the notice (commas for multiple).
- Source unit: Your office, locked.
- Date: Form date.
- Reviewers: Add or remove reviewers (up to 9). Tab in an empty name can reuse your last DCN reviewers.
- Approvals: Position and name rows (also up to 9). Tab in an empty Position can reuse your last DCN approvals.

## Save options
- Confirm checkbox: I am confirming all the inputted data are correct.
- Also create a Document Request Form (DRF) for this change after save: Optional. When checked, save continues to a prefilled New DRF; RFIU is notified once both forms are submitted.
- Preview form: Opens the printable preview (Enter in fields does not trigger it).
- Save button label: Save (cannot edit later), or Save DCN, then continue to DRF when the Also-DRF checkbox is on.

> [!NOTE]
> You cannot edit after save unless RFIU unlocks the notice for correction.
