# New Document Change Notice (DCN)
Create form CSPC-F-DCC-01 to revise an existing controlled document.

## Before the form
- Find the document to revise: Required. Search and select the registered document first.

## Fields
- New document title: Title for the revised document.
- Change From: Current text or content being changed.
- Change To: Replacement text or content.
- Justification: Reason for the change.
- Originator: Originator for the notice.
- Source unit: Your office, locked.
- Date: Form date.
- Reviewers: Add or remove reviewers (up to 9).
- Approvals: Position and name rows.

## Save options
- Confirm checkbox: Confirm the inputted data are correct.
- Also create DRF: Optional checkbox to create a Document Request Form after save.
- Preview form: Opens the printable preview.
- Save: Label becomes Save DCN, then continue to DRF when the DRF checkbox is on; otherwise Save (cannot edit later).

> [!NOTE]
> You cannot edit after save unless RFIO unlocks the notice for correction.
