# My Document Change Notices (My DCN)
List of DCNs created by your office (form CSPC-F-DCC-01).

## On this page
- New DCN: Start a change notice.
- Table columns: Title, Status (Registered / Submitted), Date, Date Created, Originator, Actions.
- View: Open the saved notice.
- DRF / Create DRF: Shown when a linked DRF applies or still needs to be created.
- Print form / locked: Control stays labeled Print form; locked until RFIU notifies print and sign.

## Rules
- Print lock: Stays locked until RFIU notifies print and sign.
- Status labels: List status is simplified. Home recent/attention cards show fuller pipeline labels.
- Full DCS / RFIU reviewers use Request under Document Registration instead of this office list.

> [!NOTE]
> After print/sign, bring the hard copy to Records. There is no online Submit to RFIU button.
