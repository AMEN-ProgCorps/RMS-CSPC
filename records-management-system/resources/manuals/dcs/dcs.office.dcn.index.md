# My Document Change Notices (My DCN)
List of DCNs created by your office (form CSPC-F-DCC-01).

## On this page
- New DCN: Start a change notice.
- Table columns: Title, Status (Registered / Submitted), Date, Date Created, Originator, Actions.
- View: Open the saved notice.
- DRF / Create DRF: Shown when a linked DRF applies.
- Print / Locked: Print when unlocked, or Locked until RFIO notifies print and sign.

## Rules
- Print lock: Stays locked until RFIO notifies print and sign.
- Status labels: List status is simplified. Home recent/attention cards show fuller pipeline labels.

> [!NOTE]
> Admin reviewers do not use this list. They use Request under Document Registration.
