# View Document Change Notice (DCN)
Read-only view of your saved DCN (CSPC-F-DCC-01).

## Header actions
- Back: Return to My DCN.
- Edit form: Available if unlocked for correction.
- Create DRF / View linked DRF: Create or open the linked DRF when applicable.
- Print form: Unlocked after RFIO notify, otherwise Locked.

## Body
- Notice fields: Title, optional document no., Change From/To, Justification.
- Origin details: Originator, source unit, date.
- Reviewers and Approvals: Read-only lists/tables.

## Banners
- Print lock / correction / registered: Same banner patterns as View DRF.

> [!NOTE]
> This page does not show a multi-revision timeline editor. It shows the saved notice content only.
