# View Document Change Notice (DCN)
Read-only view of your saved DCN (CSPC-F-DCC-01).

## Header actions
- Back to list: Return to My DCN (intake reviewers see Back to DCS).
- Edit form: Available if unlocked for correction.
- Create DRF / View linked DRF: Create or open the linked DRF when applicable.
- Print form: Always labeled Print form. When locked it is disabled with a **Print is locked** banner until RFIO notifies print and sign.

## Body
- Notice fields: Title, optional document no., From / To under Detailed Description of Change, Justification of Change.
- Origin details: Originator, source unit, date.
- Reviewers and Approvals: Read-only lists/tables.

## Banners
- Print lock / correction / registered: Same banner patterns as View DRF.

> [!NOTE]
> This page shows the saved notice content only — not a multi-revision timeline editor.
