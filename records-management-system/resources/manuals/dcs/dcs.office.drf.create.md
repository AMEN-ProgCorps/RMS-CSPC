# New Document Request Form (DRF)
Create form CSPC-F-DCC-06 for a new controlled document request.

## Entry modes
- New DRF: Normal create form.
- Recurring DRF: For yearly documents. Find the registered document first, then fill the form.
- From DCN: Continues after a change notice when linked.

## Fields you fill
- Originator: Person or office originator for the request.
- Source unit: Locked to your signed-in office.
- Date: Form date.
- Title: Official document title.
- Type of document: Internal / External (Forms and Logbooks when offered), plus internal catalog type/sub-type; syllabi fields when that type applies.
- Description / reason: Why the document is being requested.
- Distribute document to: Search offices, clusters, and chips.
- Signatories: Prepared / Reviewed / Approved (name and designation).

## Buttons
- Confirm checkbox: I am confirming all the inputted data are correct.
- Preview form: Opens printable preview. Use the button; Enter in fields does not open it.
- Save (cannot edit later): Enabled only after the confirm checkbox.
