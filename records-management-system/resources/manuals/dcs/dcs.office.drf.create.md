# New Document Request Form (DRF)
Create form CSPC-F-DCC-06 for a new controlled document request.

## Entry modes
- New DRF: Normal create form (toolbar: Back to list).
- Recurring DRF: Opened with `mode=recurring`. Complete **Find the document to recur** first (registered document no., current title, originator → Find document). Only the latest revision can be recurred. RFIU will register this as Recurring.
- From DCN: Continues after a change notice when linked. Title/originator are prefilled; document type follows the document being revised and stays locked.

## Fields you fill
- Originator: Person or office originator. Separate multiple names with commas.
- Source unit: Locked to your signed-in office.
- Date: Form date.
- Document Title: Official document title.
- Type of document: Radios for Internal / External, plus Forms / Logbooks when your campus enables those options.
  - Internal: also pick Document type and Sub-type from the catalog (Forms/Logbooks are never listed there — use the radios).
  - Syllabi-like sub-types: College, Program, Semester, Course, and School year appear when required.
- Description / reason: Why the document is being requested. Tab in an empty field can fill “For document control and dissemination”.
- Distribute document to: Search offices/clusters and select chips. Leaving this empty is allowed (office-only distribution).
- Signatories: Prepared / Reviewed / Approved (name and designation). Values often auto-fill from type, sub-type, and college.

## Buttons
- Confirm checkbox: I am confirming all the inputted data are correct.
- Preview form: Opens printable preview in a new tab. Use the button; Enter in fields does not open it or submit.
- Save (cannot edit later): Enabled only after the confirm checkbox. No file upload on this page — RFIU handles scans during registration.

> [!NOTE]
> You cannot edit after save unless RFIU unlocks the form for correction. After print/sign, bring the hard copy to Records.
