# Edit Document Request Form (DRF)
Correct a DRF only when RFIU enabled office editing.

## On this page
- RFIU asked for corrections: Alert with the reason when provided.
- Same fields as create: Originator, Source unit, Date, Document Title, Description / reason, Distribute document to, Signatories.
- Locked type: Document type / sub-type (and syllabi context when present) stay locked on edit.
- Preview form: Review the printable layout (Enter does not submit).
- Save & resubmit to RFIU: Enabled after the confirm checkbox.
- Back: Returns to View DRF.

> [!NOTE]
> If Edit form is not available on View DRF, the form is not unlocked. Wait for RFIU or check Home for Needs correction.
