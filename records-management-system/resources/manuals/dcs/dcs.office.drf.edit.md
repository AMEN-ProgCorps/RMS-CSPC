# Edit Document Request Form (DRF)
Correct a DRF only when RFIO enabled office editing.

## On this page
- RFIO asked for corrections: Alert with the reason when provided.
- Locked type: Same DRF fields as create, except document type / sub-type stay locked.
- Preview form: Review the printable layout.
- Save & resubmit to RFIO: Enabled after the confirm checkbox.

> [!NOTE]
> If Edit is not available on View DRF, the form is not unlocked. Wait for RFIO or check Home for Needs correction.
