# Random Check Result (Office)
Read-only detail of one random-check visit for your office.

## On this page
- Entire result: Show all sampled items.
- Recommended actions only: Filter to items that still need follow-up.
- Visit meta: Visit date, Conducted by, Tested by.
- Result table: Item No., Document No. (and title), Rev, Effectivity, Availability, Remarks, Recommended actions, Compliance (Complied / Not complied / blank), Notes.

> [!TIP]
> Use Recommended actions only to focus on items that still need office follow-up.
