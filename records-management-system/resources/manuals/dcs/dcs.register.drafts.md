# Draft Documents
Resume or permanently delete unfinished registration drafts.

## On this page
- Search and **All Document Types** filter, **Clear**
- Table: #, Doc Type, Title, Document No., Rev, Status (**Draft**)
- Actions: **Continue editing**, **Delete draft**

## Delete draft
- Confirmation modal: **Delete Draft Permanently?** / **Delete permanently**
- Draft deletes are permanent—they do **not** go to Recycle Bin

> [!TIP]
> Use **Continue editing** to return to Register/Edit and finish with Save Draft or Save and Appraise.
