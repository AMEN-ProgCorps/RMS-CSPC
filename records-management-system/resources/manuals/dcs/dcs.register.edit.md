# Edit / View Registration
Open an existing registration to update fields or continue a draft.

## Page state
- Badge **Editing** or **View only**
- Breadcrumb shows Update / Edit or View
- Same sectional form as Register Document (prefilled; some fields may be locked in view-only)

## Buttons by state
- **Back to List** or **Back to Drafts**
- **Generate** — distribution template when available
- Draft: **Save Draft**, **Save and Appraise**
- Registered: **Update Document**; **Update and Appraise** only when admin appraisal is still pending
- Confirm through **Review & Confirm** when saving/appraising

> [!TIP]
> Use **Update and Appraise** when distribution offices still need the appraisal/forward step after your edits.
