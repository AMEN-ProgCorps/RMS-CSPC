# Update Documents
Find registered (and draft) documents to edit, view history, or move to Recycle Bin.

## On this page
- Search, document-type filter, **Clear**
- Expandable rows for older revisions
- Status badges: **Latest**, **Superseded**, **Obsolete**, **Draft**
- Actions: **Edit**, **Edit History**, **Delete** (when allowed)

## Delete
- Requires a reason (≥5 characters)
- Button label: **Move to Recycle Bin** (HEAD review messaging)

> [!NOTE]
> This list does not edit fields inline—use **Edit** to open the registration form.
