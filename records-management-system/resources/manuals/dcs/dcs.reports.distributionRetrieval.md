# Distribution & Retrieval
Monitor which offices still need to receive distributed copies or return previous copies.

## On this page
- Filters: Document type, Status (**All open / Waiting for receipt / Not yet retrieved / Old copy still out**), Search
- Grouped table: Doc no, title, subtype, rev, Distributed / Received / Retrieved counts, Previous copy
- **Offices** button → modal listing each office Received / Retrieved / Pending return status

## Read-only
- You do not mark retrieved/received here; office receive happens on **Incoming**, retrieval updates happen during registration retrieval fields.

> [!TIP]
> Use status **Waiting for receipt** to chase offices that have not marked Incoming yet.
