# Document Masterlist Report
Generate and export controlled-document masterlist reports.

## On this page
- Title: **Document Masterlist**
- Subtype tabs: Internal, External, Internal Forms, Forms, Logbooks
- **Filter** drawer: period, dates, sort, revision status, originator, source office, rev no, sub-types
- Sort **Asc/Desc**
- Preview table
- **Export**: PDF, CSV, Print

> [!TIP]
> This is Generate Report → Masterlists. Monitoring (distribution/retrieval/syllabi) lives under the separate **Monitoring** menu.
