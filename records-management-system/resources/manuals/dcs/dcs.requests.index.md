# Request Queue
RFIO queue of office **DRF** and **DCN** submissions waiting for review.

> [!NOTE]
> Office Intake users do not use this page—they use **My DRF / My DCN**. Access requires browse-all office intake clearance.

## On this page
- Heading **Request** with pending count
- Stats: Total pending, DRF, DCN, Received, Awaiting receive
- Filters: **All / DRF / DCN**
- Table: Type, Requestor, Title, Form Date, Status (**Received** / **Pending**), Submitted, **Review**
- Auto-refreshes about every 5 seconds

## What you do next
- Click **Review** to open the request show page (notify print, receive signed copy, unlock edit, proceed to registration).

> [!TIP]
> There is no Approve/Register button on the list itself—only **Review**.
