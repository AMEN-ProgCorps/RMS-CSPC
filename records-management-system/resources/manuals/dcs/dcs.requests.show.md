# Review Request
Review one office DRF or DCN, unlock print/sign, receive the signed hard copy, then continue to registration.

## Layout
- **Back to Request**
- Print preview iframe (and tabs when both DRF/DCN previews apply)
- Title of the submission as the page heading

## RFIO action steps (in order)
1. **Notify client to print & sign** (or **Resend print & sign notice**)
2. Checkbox: **I have received the signed …**
3. **Return for correction** / **Enable edit for office** — available before receive; hides after receive
4. **Proceed to Registration** — opens Register Document with intake context (requires register permission)

## Rules
- Do not skip notify/receive gates when the workflow requires them.
- If registration was already started for this request, you are sent to continue that registration.

> [!NOTE]
> Button label is **Proceed to Registration**, not “Forward” or “Approve”.
