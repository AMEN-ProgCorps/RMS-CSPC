# Document Review
Compare PDF scans for quality control (DRR module)—not the office Request “Review” page.

## Quick compare
- Drop/select two PDF files
- **Compare files** for an ad-hoc side-by-side diff (no registration required)

## Registered documents
- Search + type filter
- **Review** opens older/newer revision PDFs side-by-side with change legend (Removed / Added / Changed)
- **Back to documents** returns to the list

> [!TIP]
> Office DRF/DCN review is under **Request**. This page is for masterlist scan comparison.
