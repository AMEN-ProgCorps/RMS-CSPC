# Settings
Maintain DCS reference catalogs used by registration, syllabi, and office forms.

## Tabs on this page
- **Document Types**
- **Signatories** (including effective dates / DRF-DCN template links where offered)
- **Originators**
- **Faculty**
- **Colleges**
- **Programs**
- **Semesters**
- **School Years**
- **Course Names** (includes bulk CSV where offered)

## Actions
- Add / edit / soft-delete catalog rows (deleted settings items go to Recycle Bin → Settings)

> [!NOTE]
> Calendar event creation is on the **Dashboard** calendar (needs Settings module to mutate)—not a tab on this Settings page. User/role admin is outside DCS Settings.
