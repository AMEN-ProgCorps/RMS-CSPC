# Stamp Document
Apply the official **Reference** stamp to a registered document’s **masterlist PDF**.

## On this page
- Search, type filter, **Clear**
- Table: type, doc no, title, rev, status, scanned PDF link, **Stamp** / **Change**

## Apply Stamp modal
- Preview page
- Stamp type **Reference**
- Auto-place or manual position; option to stamp all pages
- **Apply Stamp**, **Download Copy**, **Remove Stamp**

> [!NOTE]
> Only masterlist scans are stampable here—not DRF/DCN/distribution-only files.
