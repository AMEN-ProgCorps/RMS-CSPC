# List of Application Letters
Track and oversee all active applications, personnel endorsements, faculty appointments, and administrative requests across departments.

> [!NOTE]
> Sensitive personal documents attached to applications are governed by role-based privacy access controls.

## Search & Filters
- **Applicant Filter**: Search by applicant name, personnel ID, or position title.
- **Workflow Stage**: Filter by stage (HR Screening, Department Endorsement, Board Approval).
- **Originating College**: Filter applications submitted by specific academic departments.

## Table Columns & Actions
- **Control Number**: Click to inspect applicant qualifications, endorsements, and routing logs.
- **Applicant & Position**: Highlights the candidate's name and intended academic rank or administrative post.
- **Current Office**: Displays which office currently has custody of the application folder.
- **Action Buttons**: Review, Endorse, Forward, or Return with comments.
