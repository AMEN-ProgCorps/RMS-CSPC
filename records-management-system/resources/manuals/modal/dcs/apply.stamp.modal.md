# Apply Stamp Modal
Place the official Reference stamp on a registered document’s masterlist PDF.

## Preview panel
- Live PDF preview with stamp overlay
- **Refresh** preview
- Shows auto-detected empty area when auto-place is on

## Configuration
- **Stamp Type**: Reference
- **Auto-place in empty area** (default) or manual position map (TL / TR / C / BL / BR)
- **Stamp all pages** checkbox

## Footer
- **Cancel**
- **Download Copy** — download stamped output when available
- **Remove Stamp** — restore from unstamped backup when a stamp was applied
- **Apply Stamp** — opens the Apply Stamp confirmation before overwriting the live file

> [!NOTE]
> Only masterlist scans are stampable. Applying keeps a backup of the unstamped original for restore.
