# Calendar Event Modal
Add, edit, or delete dashboard calendar events on the admin DCS home.

## New / Edit Event
- Event date (from the selected calendar day)
- Event details and category fields shown on the form
- Save or close back to the day view

## Delete Event
- Confirms removal of the selected event from the calendar

> [!NOTE]
> Viewing the calendar is available to full DCS users. Creating or editing events/categories requires the Settings module.
