# Document Detail Modal
Inspect a registered controlled document from Dashboard Search without leaving the DCS home page.

## Header
- Document title and document number / revision label
- Close button

## Checklist tabs
- Switch among registration checklist groups (DRF, DCN, masterlist, approval, distribution, retrieval, file, and related tabs when present)
- File tab includes **Verify checksum** when a scan is available

## Revisions sidebar
- Lists other revisions of the same document
- Select a revision to switch the detail preview

## Footer actions
- **Open in Database** — opens Inventory for this document (when allowed)
- **Edit document** — opens registration edit
- **Stamp** — opens stamping for the masterlist scan (when allowed)
- **Close**

> [!NOTE]
> This modal is for admin / full DCS search results. Office Intake home does not use this Document Detail modal.
