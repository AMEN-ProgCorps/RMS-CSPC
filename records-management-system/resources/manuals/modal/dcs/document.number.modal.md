# Document Number Already Exists Modal
Appears during registration when the document number you entered conflicts with an existing number in the same group.

## Choices
- **Use next free number** — take the next available number in the group
- **Insert here and shift later numbers** — preview renames, then **Confirm shift** (optional rename of letter variants like 11A → 12A)
- **Register another copy with this number** — keep this number as its own registration without making it a revision

> [!NOTE]
> Preview the shift table before confirming. Only later numbers in the same group move up.
