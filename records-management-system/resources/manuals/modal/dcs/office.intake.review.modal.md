# RFIO Office Intake Review Modal
Quick RFIO review shell for an office DRF/DCN opened from another DCS screen.

## Header
- Kicker: RFIO review
- Submission title and subtitle
- Close

## Body
- Loaded office submission details for the selected DRF or DCN

## Footer workflow
- Banner if the submission is already registered / controlled
- Checkbox: **I have received the signed printed form and verified that the data matches this submission.**
- **Return for correction** block: reason textarea + **Enable edit for office**
- Status when a correction was already sent
- **Proceed to Registration** — enabled after receive checks pass

> [!TIP]
> Full-page Request review (`Request → Review`) shows the same workflow with print preview. This modal is the compact review shell used from other DCS screens.
