# Review & Confirm Modal
Final check before saving a Document Registration (new, revised, draft continue, or update).

## What you see
- Summary of the registration data about to be saved
- Saving banner while the submit is in progress

## Actions
- **Go Back** — return to the registration form without saving
- **Confirm Save** — commits Save Draft / Save and Appraise / Update Document / Update and Appraise

> [!TIP]
> After Confirm Save with appraisal requested, the flow continues in RDP Inventory & Appraisal—not inside this modal.
