# PDF Stamping Config
Configure header stamps, watermarks, and QR placement for controlled PDFs.

## What you set
- Stamp / watermark text and placement.
- Optional QR or document-control markers used at Review & Stamping.

## How to use
- Adjust options, preview if available, then apply before final stamping.
- Keep stamps consistent with institutional document-control rules.

> [!TIP]
> Test on a sample PDF before stamping a large batch.
