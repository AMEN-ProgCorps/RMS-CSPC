# Export & Print Manifest Modal
Configure printable reports, audit summaries, and customized document manifests for office records or compliance audits.

> [!NOTE]
> Printable manifests generate in clean, official letter/A4 print-ready layout with barcode columns.

## Configuration Options
- **Select Columns**: Choose which data fields to display (Tracking Code, Subject, Origin, Received Date, Status).
- **Date Range**: Filter printed records by custom date interval.
- **Export Format**: Choose between Browser Print, PDF Document, or Excel spreadsheet export.

> [!TIP]
> Use the column toggles to hide internal remarks when printing reports intended for external visitors or accreditors.
