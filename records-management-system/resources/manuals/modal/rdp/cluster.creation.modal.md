# Cluster Creation Modal
Combine multiple appraised inventory entries into a formal records disposition cluster for administrative batch processing.

> [!NOTE]
> Clusters allow offices to group related records (e.g., Fiscal Year 2020 Financial Records) into a single batch for appraisal review.

## Cluster Properties
- **Cluster Name**: Provide a descriptive title for the batch (e.g., "College of Engineering 2018-2022 Inventory").
- **Notes & Instructions**: Attach special handling instructions, archival warehouse coordinates, or committee notes.
