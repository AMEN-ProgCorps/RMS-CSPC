# Duplicate Offices Selection Modal
Assign duplicate copy holdings across university departments and configure electronic file access permissions.

> [!NOTE]
> Marking duplicate offices helps determine whether a copy is the primary record of origin or a convenience copy eligible for earlier disposal.

## Office Configuration
- **Search Office**: Search across all colleges and departments.
- **Toggle View Access**: Decide whether recipient duplicate offices have permission to preview digital file attachments.
- **Spread to Offices**: Distribute notifications to all listed duplicate holding offices.
